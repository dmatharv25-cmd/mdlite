A Lennard-Jones liquid, live

This page is a JavaScript port of the algorithm, using brute-force pair loops and reduced units (σ = ε = m = 1, dt = 0.004, cutoff 2.5σ, shifted potential, no long-range correction), so it runs without Python. The Python and Numba engine in the mdlite repository is the code validated against NIST reference data.
